# trainingbots
A /bot plugin for crystalpvp practice servers (mainly). Works for Mace/Cart servers as well.


**Commands**
/bot - Opens the Bot GUI
/bot spawn - Spawns the bot
/bot remove - Removes the current bot
/bot help - Sends a "help" message

**trainingbots.admin**/operator
/bot reload - Reloads the config


**Functions**

If a player 2 is within 100 blocks of player 1 the bot despawns. 

**Bot Addons**

IMMORTALITY - Make yourself immortal while fighting the bot. 
SHEILD - The bot holds a shield, holds another one after a stun.
GLOWING - Gives the bot glowing, works even after pop.
LOOK-AT-PLAYER - Look at the closest player.

Armor - Change between blast protection and protection. ( Diamond/Netherite SOON ).
